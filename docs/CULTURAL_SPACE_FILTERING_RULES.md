# 서울시 문화공간 데이터 변환·필터링 규칙

상태: 운영 규칙  
최종 갱신: 2026-09-10  
적용 대상: 서울시 문화공간 정보 CSV를 새로 받거나 갱신할 때마다 수행하는 전체 재처리

## 1. 목적

서울시 문화공간 원본을 서비스의 관광지 CSV 구조로 변환하고, 서비스 대상이 아닌 시설과 한국관광공사 데이터의 중복 장소를 일관되게 제거한다.

이 문서는 특정 스냅샷의 행 번호가 아니라 **매 갱신 때 다시 적용해야 하는 판정 규칙**을 정의한다. 데이터가 갱신되면 과거 결과 CSV에 새 행을 덧붙이지 말고 새 원본에서 전체 변환과 필터링을 다시 수행한다.

## 2. 입력과 출력

입력:

- 서울시 문화공간 원본: `data/newData/서울시 문화공간 정보_utf8.csv`
- 한국관광공사 기준 데이터: `data/newData/attractions.csv`

출력:

- 기본 데이터: `data/newData/processed/cultural_space_attractions.csv`
- 상세 데이터: `data/newData/processed/cultural_space_details.csv`

두 출력 파일은 하나의 데이터 묶음이다. 기본 데이터에서 행을 제외하거나 삭제하면 같은 `place_id`의 상세 데이터도 반드시 함께 제거한다. 상세 데이터만 단독으로 추가하거나 유지하지 않는다.

## 3. 식별자 계약

| 값 | 저장 위치 | 규칙 |
|---|---|---|
| 원본 `번호` | 두 파일의 `place_id` | 문자열로 그대로 보존 |
| 기본 데이터 `id` | `id` | 항상 공백; DB 적재 시 생성 |
| 관광공사 식별자 | `tourism_content_id` | 문화공간 행에는 저장하지 않음 |

필터링 전후에 다음 조건을 모두 만족해야 한다.

- `place_id`가 비어 있지 않다.
- 각 파일 안에서 `place_id`가 중복되지 않는다.
- 기본 파일과 상세 파일의 `place_id` 집합이 정확히 같다.
- 두 파일의 행 수도 같다.

## 4. 기본 데이터 변환

기본 파일의 헤더와 컬럼 순서는 `attractions.csv`와 동일하게 유지한다.

| 원본 컬럼 | 기본 데이터 컬럼 | 규칙 |
|---|---|---|
| `번호` | `place_id` | 그대로 보존 |
| `문화시설명` | `place_name` | 앞뒤 공백 제거 |
| `주소` | `address_name`, `road_address_name` | 두 컬럼에 동일하게 저장 |
| `경도` | `map_x` | 경도 |
| `위도` | `map_y` | 위도 |
| `전화번호` | `phone` | 그대로 저장 |
| `대표이미지` | `image_url` | 그대로 저장 |
| `주제분류` | `category_name` | `문화시설 > {주제분류}` |

공통값:

- `category_group_name=문화시설`
- `image_url_overridden=f`
- `source=SEOUL_CULTURAL_SPACE`
- `tourism_content_id`는 공백
- `place_url`은 공백으로 두고 홈페이지는 상세 파일에만 저장

원본에서 기본 또는 상세 출력에 매핑하지 않은 컬럼은 버린다.

## 5. 상세 데이터 분리

상세 파일은 다음 컬럼만 이 순서로 보존한다.

1. `place_id`
2. `홈페이지`
3. `관람시간`
4. `관람료`
5. `휴관일`
6. `객석수`
7. `기타사항`
8. `시설소개`

상세정보는 기본 데이터와 `place_id`로 조인한다. 홈페이지를 기본 데이터의 `place_url`로 복사하지 않는다.

## 6. 유형 매핑과 기본 제약

| 원본 `주제분류` | `primary_type` | `primary_type_name` | `is_indoor` | `is_heat_source` | `is_massage_spot` | `walk_hard` |
|---|---|---|---:|---:|---:|---:|
| 미술관/갤러리 | `cultural_facility` | 미술관 | `t` | `f` | `f` | 3 |
| 공연장 | `cultural_facility` | 공연장 | `t` | `f` | `f` | 2 |
| 박물관/기념관 | `cultural_facility` | 박물관 | `t` | `f` | `f` | 3 |
| 문화원 | `cultural_facility` | 문화원 | `t` | `f` | `f` | 2 |
| 문화예술회관 | `complex_cultural_space` | 복합문화공간 | `t` | `f` | `f` | 4 |
| 기타 | `cultural_facility` | 관광지 | `t` | `f` | `f` | 3 |

추가 공통값은 `is_na=f`다.

`관광지`는 현재 문화공간 데이터에 한해 사용하는 프로젝트 정책값이다. 현재 정규 명세인 `PRIMARY_TYPE_MAPPING_RULES.md`의 고정 17개 표시명에는 없으므로, 최종 병합 검증기를 엄격하게 적용하기 전에 두 규칙을 동기화해야 한다.

## 7. 자동 제외 규칙

### 7.1 원본 유형 제외

원본 `주제분류=도서관`인 행은 모두 제외한다.

### 7.2 장소명 포함 문자열 제외

`place_name`에 다음 문자열 중 하나라도 포함되면 제외한다. 일치는 대소문자 구분 없이 **포함 여부**로 판정하며, 문자열 사이의 공백을 임의로 제거해서 판정하지 않는다.

- `체육센터`
- `교육센터`
- `체육관`
- `여성문화센터`
- `구민회관`
- `대학교`
- `청소년`
- `마을활력소`
- `문화회관`
- `댄스하우스`
- `문화재단`
- `문화센터`
- `캠퍼스`
- `지원센터`

한 행이 여러 제외 문자열에 동시에 해당해도 한 번만 제외한다.

### 7.3 명시적 제외

- `place_id=762`: 서울시민대학 다시가는 캠퍼스

원본 갱신으로 `번호`가 재발급될 가능성이 있으면 이름도 함께 확인한다. 명시적 제외 목록을 추가할 때는 `place_id`, 당시 장소명, 제외 이유를 함께 기록한다.

## 8. 한국관광공사 데이터와 중복 제거

중복 데이터의 생존 우선순위는 다음과 같다.

```text
한국관광공사 attractions.csv > 서울시 문화공간 데이터
```

중복으로 확정되면 문화공간 기본 파일과 상세 파일에서 해당 `place_id`를 함께 제거한다. 관광공사 행은 수정하지 않는다.

### 8.1 정규화

장소명:

- 소문자로 변환한다.
- 공백과 구두점 등 영문·숫자·한글이 아닌 문자를 제거한다.

주소:

- 앞뒤 및 연속 공백을 정리한다.
- `서울특별시`와 `서울`을 동일하게 취급한다.
- 괄호와 괄호 안 내용을 제거한다.
- 나머지 공백과 구두점을 제거한다.

### 8.2 중복 판정

다음 조건을 순서대로 적용한다.

1. 정규화된 장소명과 정규화된 도로명주소가 모두 같으면 중복이다.
2. 정규화된 장소명과 정규화된 지번주소가 모두 같으면 중복이다.
3. 두 좌표의 Haversine 거리가 30m 이하이고 정규화된 장소명 유사도가 0.72 이상이면 중복 후보다.
4. 전체 시설과 내부 시설처럼 장소의 범위가 다를 수 있는 후보는 수동 검수한다.

주소가 정확히 일치하면 제공처별 좌표 오차가 30m를 넘어도 중복으로 판정할 수 있다.

### 8.3 확정된 수동 판정

| 문화공간 `place_id` | 문화공간 장소 | 관광공사 장소 | 판정 |
|---:|---|---|---|
| 204 | 현대카드 아트 라이브러리 | 현대카드 뮤직 라이브러리 | 서로 다른 시설, 문화공간 유지 |
| 642 | 서울성북미디어문화마루 꿈빛극장 | 서울성북 미디어문화마루 | 중복, 문화공간 제거 |
| 1002 | KT&G 상상마당 홍대 갤러리 | KT&G 상상마당 홍대 | 중복, 문화공간 제거 |

`place_id=204`는 알고리즘상 거리·이름 유사도 후보가 되지만 중복이 아니다. 향후 재실행에서도 자동 삭제하지 않는다.

## 9. 실행 순서

1. 새 서울시 원본을 UTF-8 BOM CSV로 준비한다.
2. 원본 전체를 기본 데이터와 상세 데이터로 다시 변환한다.
3. 두 파일의 초기 `place_id` 집합이 같은지 검사한다.
4. `주제분류=도서관`을 제외한다.
5. 장소명 자동 제외 문자열을 모두 적용한다.
6. 명시적 제외 목록을 적용한다.
7. 유형 매핑과 기본 제약값을 적용한다.
8. 최신 관광공사 `attractions.csv`와 중복 검사를 다시 수행한다.
9. 수동 예외를 반영하고 확정 중복의 문화공간 행을 두 파일에서 제거한다.
10. 최종 검증을 통과한 파일만 적재 대상으로 사용한다.

필터 하나를 적용할 때마다 두 파일을 각각 따로 판단하지 않는다. 기본 파일에서 제거할 `place_id` 집합을 먼저 만든 다음 동일한 집합을 두 파일에 적용한다.

## 10. 최종 검증

처리가 끝나면 다음을 모두 확인한다.

- 기본 파일과 상세 파일의 행 수가 같다.
- 두 파일의 `place_id` 집합이 정확히 같다.
- 두 파일 모두 빈 `place_id`와 중복 `place_id`가 0건이다.
- 기본 파일의 `id`는 모두 공백이다.
- 도서관 및 장소명 제외 문자열이 남아 있지 않다.
- `place_id=762`가 남아 있지 않다.
- 미술관·박물관은 `walk_hard=3`이다.
- 공연장·문화원은 `walk_hard=2`이다.
- 복합문화공간은 `walk_hard=4`이다.
- 관광지는 `is_indoor=t`, `is_heat_source=f`, `is_massage_spot=f`, `walk_hard=3`이다.
- 관광공사와 확정 중복인 문화공간 행이 남아 있지 않다.
- 알려진 비중복 예외인 현대카드 아트 라이브러리는 유지된다.
- 두 CSV는 UTF-8 BOM 형식이다.

## 12. 관련 파일

- 변환기: `scripts/transform_cultural_spaces.py`
- 변환 테스트: `tests/test_transform_cultural_spaces.py`
- 공통 유형 명세: `docs/PRIMARY_TYPE_MAPPING_RULES.md`

현재 변환기는 기본 분리까지만 담당하고, 이 문서의 누적 필터와 관광공사 중복 제거 전체를 자동화하지 않는다. 새 데이터 갱신 시 누락을 막으려면 다음 단계에서 이 문서의 규칙을 변환기에 통합하고 회귀 테스트로 고정하는 것이 권장된다.
