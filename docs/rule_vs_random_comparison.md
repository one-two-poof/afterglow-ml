## 읽는 법

- **제약**: 시나리오의 indoor / forbid_categories / walk_hard + `mobility_range`의 `max_allowable_dist` (+ 쇼핑 시 마사지·스파 금지)
- **시나리오 입력 (필드 분리 후)**: 기본 `activity_level = mobility_range` (구 `walk`와 동일 의미). 활동만 달리 보려면 시나리오에서 `activity_level` 지정
- **목적 적합**: `PURPOSE_HINTS` 소분류. 문화는 설계상 3번이 쇼핑이라 규칙 점수가 낮게 나올 수 있음
- **1번 슬롯**: `SLOT1_HINTS` (코스 첫 장소)
- **유니크**: 랜덤도 가능하면 재사용 안 함 → 둘 다 100%에 가까움
- **현재 규칙 기준선**: 아래 「필드 분리」절의 규칙 vs 랜덤 표. 맨 위 「요약 표」는 초기 기준선(슬롯 완화 전) 보존용

## 해석

규칙 기반이 랜덤 대비:

1. **제약** — 시나리오 단위 통과 100% vs 33%. 시술·mobility_range 한도를 실제로 지킴
2. **목적** — 특히 1번 슬롯(85% vs 29%)과 쇼핑 목적에서 우위
3. **동선** — max hop·총거리가 약 1/3 수준으로 짧음
4. **다양성** — 하루 카테고리 수↑, 연속 동일 카테고리↓ (최근 재배치 제약 반영)

문화 일부 시나리오에서 랜덤의 “목적 소분류 %”가 규칙보다 높게 나온 것은, 규칙이 일부러 3번을 쇼핑으로 끝내는데 그 쇼핑을 문화 힌트로 세지 않기 때문.

## 변경 이력: 슬롯 가산 완화 (2026-09-05)

### 작업 내용

- `_select_place_by_mmr`에서 슬롯 키워드 하드 풀(`slot_near_unique` / `slot_near_repeat`) 우선 제거
- 후보 풀: 목적 키워드 근처 → near unique → unique → eligible (슬롯은 `_slot_score` 소프트 가산만)
- `course_flow_rule` bonus: slot 1·2 `2.0`→`1.0`, slot 3 `2.5`→`1.5`
- `early_shopping_penalty`: `-1.5`→`-0.8` (문화관광·휴식)

## 변경 이력: mobility_range / activity_level 분리 (2026-09-06)

### 작업 내용

- 요청 필드 `user_walk_preference` 제거 → `mobility_range`(동선 반경) + `activity_level`(장소 활동 난이도)로 분리
- `mobility_range` → `preference_tables` / hop / `slot_max_hop_by_mobility`
- `activity_level` → `walk_hard` 점수 매칭 (`activity_level_rule`)
- 오프라인 시나리오: 분리 전 `walk` 단일값과 같게 `activity_level = mobility_range`로 맞춤 (직전 슬롯 완화 측정과 동일 입력 의미). `activity_level`만 따로 두려면 `_scenario(..., activity_level=N)`으로 지정
