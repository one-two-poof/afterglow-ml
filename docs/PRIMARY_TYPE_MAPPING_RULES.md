# primaryTypeName 고정 목록과 카카오 카테고리 매핑 규칙

상태: 정규 명세  
규칙 버전: `1.1.0`  
기준일: 2026-08-29  
적용 범위: 모든 지역의 신규 수집·재분류·최종 병합

## 1. 핵심 결정

- `primaryTypeName`은 아래 17개 값만 허용하는 폐쇄형 목록이다.
- 처음 보는 카카오 카테고리를 발견해도 새 표시명을 자동 생성하지 않는다.
- 불확실한 값은 기존 유형에 억지로 넣지 않고 `UNMAPPED` 보고서로 보낸다.
- 최종 CSV에 컬럼을 추가하지 않으며 원본 `categoryName`을 보존한다.
- `자연`으로 통합한 산·섬·숲의 차이는 원본 경로로 다시 판정한다.

“전체 매핑”은 카카오의 비공개 전체 분류체계를 복제한다는 뜻이 아니라, **우리 서비스 지원 범위를 빠짐없이 판정하는 규칙**을 뜻한다.

## 2. 카카오 API의 공개 범위

장소 응답의 `category_name`이 상세 경로이며 주 판정 근거다. `category_group_code`와 `category_group_name`은 검색·검증 보조이고, `place_name`은 이 문서가 허용한 경우에만 보조 신호로 쓴다.

|---|---|---|---|
| `MT1` | 대형마트 | `CS2` | 편의점 |

카카오는 세부 카테고리 전체 목록과 분류 기준을 공개하지 않으며, DevTalk에서는 전체 상세 구조를 취합해 사용하는 것도 제한한다고 안내한다. 공개 API에서 우리 검색 결과로 정상 취득한 경로만 판정에 사용하고 전체 체계를 크롤링·역공학하지 않는다.

## 4. 정규화와 판정 우선순위

판정용 경로는 `>`로 나눈 각 세그먼트의 공백과 빈 값을 정리한 뒤 ` > `로 연결한다. 원본은 수정하지 않는다.

| 표기 | 의미 |
|---|---|
| `=` | 전체 경로 정확 일치 |
| `^` | 해당 경로와 모든 하위 경로 |
| `SEG` | 경로 세그먼트 정확 일치 |
| `NAME` | 장소명 보조 신호 |
| `REVIEW` | 자동 확정 금지, 수동 검수 |

판정 순서는 필수 필드·주소 검증 → 전역 제외 → 유형별 제외 → 정확 경로 → 하위 경로/세그먼트 → 그룹 코드 보조 → 허용된 장소명 보조 → 수동 검수 → `UNMAPPED`다. 제외가 허용보다 항상 우선한다. 검색어와 그룹 코드만으로 최종 유형을 확정하지 않는다.

### 웰니스

카카오 카테고리와 장소명은 **후보 발견 근거**이고, 열원·마사지 제공 여부는 상세정보 또는 수동 검수로 확정한다. `스파`라는 단어 하나만으로 `spa(1/1)`를 부여하지 않는다.

| ID | 후보가 되는 정확한 조건 | 필수 확정 조건 | `primaryType` | 표시명 | 열원/마사지 |
|---:|---|---|---|---|---|
| W01 | `가정,생활 > 목욕탕,사우나 ^` 또는 `여행 > 관광,명소 > 온천 ^` | 사우나·찜질·목욕·온천 중 하나를 실제 제공하고 마사지 제공은 확인되지 않음 | `heat_source` | 찜질방/사우나 | `1/0` |
| W02 | `가정,생활 > 미용 > 발관리 ^`, `... > 체형관리 ^`, `... > 피부관리 ^` 또는 장소명에 마사지·안마·경락 신호 | 마사지·안마·경락·발마사지·수기 테라피 중 하나를 실제 제공하고 열원 제공은 확인되지 않음 | `massage_spot` | 안마/스파 | `0/1` |
| W03 | W01과 W02 후보가 모두 성립하거나 장소명·상세정보에 `스파`가 있음 | 열원 서비스와 마사지 서비스를 **각각 별도 근거로 모두 확인** | `spa` | 안마/스파 | `1/1` |

#### 후보 신호와 확정 신호

| 판정 대상 | 후보 신호: 이것만으로 확정 금지 | 확정 신호: 상세정보·시설 안내에서 확인 |
|---|---|---|
| 열원 | 카테고리 `목욕탕,사우나`·`찜질방`·`온천`, 장소명 사우나·찜질방·스파·온천 | 사우나실, 찜질시설, 목욕탕·탕, 온천수, 스팀룸 등 실제 이용 시설 |
| 마사지 | 카테고리 `발관리`·`체형관리`·`피부관리`, 장소명 마사지·안마·경락·테라피·스파 | 마사지, 안마, 경락, 발마사지, 수기 테라피 등 실제 예약 가능한 서비스 |

판정 순서는 다음과 같다.

1. 카테고리 경로로 후보를 만든다.
2. 장소명 신호는 후보를 보강할 뿐 제약값을 확정하지 않는다.
3. popularity 4 이상만 상세 검수 대상으로 남긴다.
4. 상세정보에서 `verifiedHeat`와 `verifiedMassage`를 각각 판정한다.
5. `1/1 → spa`, `1/0 → heat_source`, `0/1 → massage_spot`으로 매핑한다.
6. `0/0`이거나 서비스 확인에 실패하면 제외하거나 `isNa=1` 검수 파일로 보낸다.

`온천`은 열원만 확실하므로 기본적으로 W01이다. 실제 마사지까지 별도로 확인된 경우에만 W03으로 승격한다. 반대로 상호에 `스파`가 있어도 마사지와 열원 중 하나만 확인되면 확인된 단일 유형으로 분류한다.

자동 제외 경로는 `체형관리 > 다이어트,비만 ^`, `체형관리 > 칼로리바 ^`, `체형관리 > 다이어트,비만 > 단식원 ^`이다. 상세정보에서 실제 수기 마사지를 확인한 경우에만 수동 예외를 허용한다. 출장마사지, 성인업소, 중개업체, 투숙객 전용 시설, 화장품 판매점, 마사지 없는 병·의원도 제외한다.

| 백화점, 쇼핑몰, 복합문화공간, 수목원, 둘레길, 대형 공원 | 유형 기준 | 0 | 0 | 4 |
| 산, 숲 | 0 | 0 | 0 | 5 |

덮어쓰기 우선순위는 다음과 같다.

1. 산·등산·봉·고개·능선 또는 한강공원·호수공원·수변공원·숲길 → 5
2. 둘레길·생태공원·수목원 → 4
3. 유형별 기본값

더 높은 난이도 신호가 우선한다.

## 8. 전역 제외와 신규 값 처리

전역 제외: ID·좌표 없음, 대상 구 외 주소, 폐점·운영 실체 없음, 롭스앤그레이·디벨롭스 계열 오탐, 화장품·렌즈점의 드럭스토어 오분류, 시설 부대 장소, 카페 외 음식점, 현재 정책상 제외된 서점·도서관.

처음 보는 경로는 다음처럼 처리한다.

1. 최종 CSV에 넣지 않는다.
2. ID, 장소명, 전체 경로, 그룹 코드, 발견 구, 건수를 별도 `unmapped_categories` 보고서에 기록한다.
3. 표본 검수 후 기존 17개에 정확히 맞을 때만 이 문서에 규칙을 추가한다.
4. 맞는 값이 없어도 작업자가 새 표시명을 만들지 않는다.

`기타`, `자연`, `복합문화공간` 같은 포괄 fallback은 금지한다.

## 9. 버전과 자동 검증

설명만 바뀌면 패치, 기존 목록 안의 경로가 바뀌면 마이너, 표시명 추가·삭제·의미 변경은 메이저 버전을 올린다. 메이저 변경은 데이터 재분류, `app/config/rule_config.yaml`, 프론트 아이콘, 회귀 테스트를 함께 검토한다.

최종 병합 조건:

- 표시명이 고정 17개 중 하나이고 허용된 `primaryType` 조합이다.
- 허용 규칙과 일치하고 제외 규칙에는 일치하지 않는다.
- `UNMAPPED`와 `isNa=1`이 0개다.
- 산·섬·숲의 원본 `categoryName`이 보존된다.
- 정수 필드가 실제 정수다.
- 카페는 popularity 5, 웰니스는 4 이상과 수동 검수를 충족한다.
- 입력·제외·미매핑·최종 건수를 실행 보고서에 남긴다.

## 10. 현재 데이터에서 관측한 경로

강남·서초 및 추가 구 데이터에서 드럭스토어·올리브영, 백화점과 브랜드, 복합쇼핑몰, 상설할인매장·뉴코아아울렛, 문화시설과 공연장·연극극장·기념관·문화원·미술관·전시관·박물관·아쿠아리움, 영화관과 브랜드, 공원·도시근린공원, 도보여행·둘레길·산·섬·섬(내륙)·숲·테마거리·먹자골목·테마파크·온천·수목원·식물원, 카페 하위 경로, 목욕탕·사우나·찜질방, 발관리·체형관리·피부관리·두피탈모관리 경로를 확인했다.

렌즈 판매 경로가 드럭스토어로 오분류된 과거 사례가 있으므로 `드럭스토어` 세그먼트 없는 안경·렌즈 경로는 제외한다. 이 목록은 카카오 전체 분류표가 아니라 회귀 테스트용 관측 목록이다.
